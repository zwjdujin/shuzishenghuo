隐私政策

⚡ 30 秒速览
  • 本官网不收集任何数据：纯静态页面，无 Cookie、无统计、无追踪、无广告。
  • 应用数据 100% 在你自己手里：自托管的数字生活把全部数据存在你自己的 Cloudflare 账号（D1 数据库 + R2 存储），项目开发者不运营任何服务器，也收不到你的任何数据。
  • 无遥测：应用前端与后端均无埋点、无上报、无第三方统计脚本。
  • 仅有的第三方数据流都由你主动开启：AI 速记（发送到你自己配置的模型服务商）、Web Push（经浏览器厂商推送通道）、可选的文楷字体（从 jsDelivr 加载）。
  • 随时带走：站内一键下载全量 JSON 备份，或清空重建——数据生命周期完全由你掌控。

一、适用范围

本政策适用于：

  • 数字生活官方网站（本页面所在的静态站点）——介绍项目、提供文档链接的纯展示页面；
  • shuzishenghuo 开源项目及其代码，以及你按照部署指南自行部署的实例（下称「自托管实例」）。

数字生活是一款自托管的单管理员个人工作台：部署完成后，站点运行在部署者自己的 Cloudflare 账号里，数据也只落在该账号中。因此，对于你的自托管实例而言，你（部署者）就是数据的唯一控制者；项目开发者不是任何实例的数据处理者或接收者。

二、本官网收集什么

答案很简单：什么都不收集。

  • 无 Cookie：本官网不设置任何 Cookie，也不使用 localStorage 等浏览器存储。
  • 无统计与追踪：不加载任何分析脚本（如 Google Analytics、百度统计等），不使用广告或社交追踪像素，页面内除 GitHub 仓库外不含第三方资源请求。
  • 无表单：官网没有任何输入框或提交接口，我们无法收集你的姓名、邮箱或任何身份信息。
唯一需要说明的基础设施事实：本官网静态托管在 Cloudflare Pages 上。作为托管服务方，Cloudflare 会按其自身的隐私政策记录标准访问日志（如请求 IP、时间、User-Agent），这类日志由 Cloudflare 处理，项目开发者无法据此识别具体个人，也不将其用于任何用途。参见 Cloudflare 隐私政策。

三、自托管实例：数据存在哪里

数字生活的设计原则是「数据不出你的账号」。你的自托管实例中，各类数据的存储位置如下：

数据存储位置说明
账本、待办、习惯打卡、药品、联系人、日程、经期记录、备忘等结构化数据你自己的 Cloudflare D1 数据库部署时由你创建并绑定到 Pages 项目
联系人附件（照片 / 视频 / 文档）你自己的 Cloudflare R2 存储桶不使用任何第三方图床或对象存储

Web Push 订阅（endpoint、加密密钥）你的 D1（push_subscriptions 表）仅用于向你自己的设备推送提醒
界面偏好（主题、字体、隐私开关等）你浏览器的 localStorage不包含个人数据，不上传

项目开发者（本仓库维护者）不运营任何用于数字生活的服务器，不持有任何实例的密钥，也不接收、备份或查看任何实例的数据。Cloudflare D1 与 R2 的数据处理行为，受你与 Cloudflare 之间的服务条款与隐私政策约束。

四、第三方数据流（仅当你自行启用时发生）

数字生活默认零第三方数据共享。以下数据流只有在部署者主动配置、或用户主动选择时才会发生：

1. AI 速记解析（可选）

  • 触发条件：部署者在站内「个人中心 → 智能管理」添加了大模型（OpenAI 兼容接口），且你使用了随手记的 AI 解析功能。
  • 发送内容：仅发送你随手记中输入的文本（单次不超过 200 字）；只有当你为模型勾选了「支持图片」，才会附带你主动粘贴的图片。
  • 接收方：部署者自行配置的模型服务商（如智谱、OpenAI 或任何兼容接口）。数据发往该服务商并受其隐私政策约束。
  • 不发送内容：账本、联系人、药品等其他模块的数据，以及你的登录凭据，不会发送给模型服务商。
  • 退出方式：不配置模型即完全关闭；配置后也可随时删除。

2. Web Push 推送提醒（可选）

  • 触发条件：部署者按 PUSH_SETUP.md 部署了提醒 Worker，且你在浏览器中授权了通知。
  • 数据流：提醒经你自建的 Worker 发出，通过浏览器厂商的推送通道（Chrome / Firefox / Safari 等系统级推送服务）送达你的设备——这是 Web Push 标准的必经通道。推送内容负载按标准端到端加密（VAPID + payload 加密），推送服务商无法读取通知正文。
  • 存储内容：订阅信息（endpoint、p256dh、auth 密钥）仅保存在你自己的 D1 中，用于定向发送，不与任何第三方共享。
  • 退出方式：在浏览器通知设置中关闭，或删除对应浏览器订阅记录。

3. 可选网络字体（霞鹜文楷）

  • 应用的默认字体是系统字体，不发生任何外部请求。
  • 只有当你在「个人中心 → 主题风格」主动选择「霞鹜文楷」时，浏览器才会从 jsDelivr CDN 加载该开源字体文件；此时 CDN 会看到你的请求（含 IP）。换回默认字体即不再发生。

4. Cloudflare（托管基础设施）

  • 你的自托管实例本身就是部署在 Cloudflare 免费套餐上（Pages / D1 / R2 / Workers）。这些是运行站点所必需的基础设施，数据处理行为受 Cloudflare 服务条款与隐私政策约束。

五、安全实践

以下均为开源代码中可查验的实现（相应文件见仓库）：

  • 密码存储：管理员密码修改后以 PBKDF2-SHA256 加盐哈希（100,000 次迭代）存于数据库，不存明文；该键不在任何 API 的读取白名单内，无法通过接口读出。
  • 会话：登录态使用 HMAC-SHA256 签名的 Cookie（sz_session），属性为 HttpOnly; SameSite=Lax，有效期 7 天，HTTPS 下附加 Secure；JS 无法读取该 Cookie。
  • API Token / MCP：令牌明文（szsh_ 前缀）只在生成时显示一次，数据库中仅存 SHA-256 哈希；令牌按功能点授权读写范围，可随时吊销，吊销立即生效。
  • 传输：站点通过 Cloudflare 强制 HTTPS。
  • 备份文件：全量备份（JSON）仅在你点击下载时由浏览器生成，保存到你本地，不经任何中间方。

部署者也应遵循基本安全实践：设置强管理员密码与足够随机的 SESSION_SECRET，不要将环境变量泄露到公开仓库。

六、你的数据权利

由于一切数据都在你自己的账号里，以下权利天然由你完全行使：

  • 访问与导出：站内「个人中心 → 数据安全」一键下载全量 JSON 备份；D1 / R2 数据也可通过 wrangler 或 Cloudflare 控制台直接访问。
  • 更正：站内直接编辑任何记录。
  • 删除：删除单条记录、单个附件，或使用「清空重建」清空全部数据；删除 Cloudflare 中的资源即彻底删除数据。
  • 可携带：JSON 备份为通用格式，随时迁往任何地方。

七、数据保留

自托管实例的数据保留策略由部署者决定：数据持续保存在你的 Cloudflare 账号中，直到你删除。本官网不保留任何用户数据。
