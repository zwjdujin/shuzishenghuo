部署上线

约 20 分钟，把站点搬进你的账号

不需要写代码，全程照抄命令即可。完整图文版见 DEPLOY.md 零基础部署指南。

  1. 1

    准备账号与工具

    注册 Cloudflare（免费套餐就够用），安装 Node.js LTS 与命令行工具 wrangler，Fork 本仓库到你的 GitHub。

    npm install -g wrangler && wrangler login
  2. 2

    创建 D1 数据库与 R2 存储桶

    名称均填 shuzishenghuo（控制台或命令行皆可），把数据库 ID 填进 wrangler.toml。

    wrangler d1 create shuzishenghuo
    wrangler r2 bucket create shuzishenghuo
  3. 3

    连接 Cloudflare Pages

    Workers 和 Pages → Pages → 连接 Git 仓库；构建命令留空，构建输出目录填 public。

  4. 4

    配置环境变量

    设置管理员账号与会话密钥：三个变量缺一不可。

    ADMIN_USER · ADMIN_PASS · SESSION_SECRET
  5. 5

    绑定数据库与存储桶

    Pages 项目 → 设置 → 绑定：D1 数据库绑定为 DB，R2 存储桶绑定为 BUCKET，保存后重新部署。

  6. 6

    初始化数据库，开始使用

    应用全部数据库迁移，然后打开 你的项目名.pages.dev 登录，去「个人中心」挑一个喜欢的主题。

    wrangler d1 migrations apply shuzishenghuo --remote

常见问题

你可能想问

需要会写代码吗？

不需要。DEPLOY.md 是为零基础写的完整部署指南，全程复制粘贴命令，约 20~30 分钟（大部分是等待）。还有不用 GitHub 的一键部署脚本。

我的数据存在哪里？安全吗？

数据只存在你自己的 Cloudflare 账号里（D1 数据库 + R2 对象存储），不经过任何第三方。「数据安全」页可以随时下载全量 JSON 备份，随时可迁走。

真的 0 成本吗？以后会不会收费？

个人使用完全落在 Cloudflare 免费额度内：Pages 请求数不限、D1 每天 500 万行读取、R2 10GB 存储。数字生活本身开源免费，也不存在订阅。免费额度以 Cloudflare 官方政策为准。

手机上怎么用？

用手机浏览器打开站点 → 菜单 →「添加到主屏幕」，即可全屏当 APP 用（PWA）。也可以按 TWA_BUILD.md 打包成 APK 安装包侧载。

推送提醒怎么开启？

推送是可选项：按 PUSH_SETUP.md 额外部署一个小 Worker 并配置 VAPID 密钥即可。待办与服药到点每分钟检查，生日 / 保持联系 / 药品临期每天早上提醒。

AI 功能必须配置吗？

可选。在站内「个人中心 → 智能管理」添加一个大模型（OpenAI 兼容接口，如智谱 GLM）并填入 API Key，随手记即可自动解析；不配置也不影响其他任何功能。

能给家人一起用吗？

目前是单管理员模式，适合个人或家庭自用（知道账号密码即可共用）。多用户方案在规划中。

部署遇到问题怎么办？

先查 DEPLOY.md 文末常见问题表：接口 401 多为环境变量未配好；模块全部加载失败多为数据库 ID 未替换或绑定缺失；附件上传失败多为 R2 桶未创建；也可到 GitHub 提 Issue。
